# User Profile

## Role & Context

- **Role**: Full-stack developer / Project lead
- **Experience**: Senior level, comfortable with React & NestJS
- **Project ownership**: Primary developer, manages AI coding agents

## Communication Preferences

- **Language**: Vietnamese for discussion, English for code/docs
- **Detail level**: Concise responses preferred, skip obvious explanations
- **Code explanations**: Focus on "why", not "what"
- **Status updates**: Brief summaries, show progress through todo list

## Workflow Preferences

- **Planning**: Likes structured plans before implementation
- **TDD**: Prefers test-first approach for new features
- **Code review**: Wants review after each significant change
- **Commits**: Prefers detailed conventional commit messages

## Coding Style Preferences

- **Immutability**: Strong preference for immutable patterns
- **File size**: Prefers many small files over few large ones
- **TypeScript**: Strict mode, avoid `any`, explicit return types
- **Comments**: Minimal, only for non-obvious logic

## Tool Preferences

- **AI Agent**: Claude Code (primary)
- **Editor**: VSCode
- **Terminal**: zsh on macOS
- **Package Manager**: yarn for frontend, npm for backend

## What to Avoid

- Don't explain basic React/NestJS concepts
- Don't suggest over-engineering solutions
- Don't add unnecessary abstractions
- Don't create files without clear purpose
